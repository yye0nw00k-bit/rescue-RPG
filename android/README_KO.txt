태현이 구하기(?) - Android APK 프로젝트
========================================

포함 기능
- 13개 지역과 각 지역 수호 보스
- 첫 12개 보스 격파 뒤 서로 다른 인물이 등장해
  "태현이는 여기에 없어요. 일단 이거 받으세요."라고 말하고 보상 지급
- 13번째 최종 보스 격파 뒤 이름표가 '태현'인 인물이 등장해
  로그인한 닉네임을 넣어 "고마워요 [닉네임], 환생할 기회를 줄게요."라고 말함
- 환생 시 시작 능력치 보너스
- 회원가입/로그인, 계정별 로컬 저장, 모바일 터치 조작
- 연욱 관리자 계정: 아이디 연욱 / 비밀번호 151013
- 자동 공격, 점프, 스킬, 회복 물약, 성장, 상점, 지도, 임무, 저장

중요 사항
- 이 폴더는 APK를 만들기 위한 소스 프로젝트입니다. 여기에는 컴파일된 .apk 파일 자체는 없습니다.
- APK 빌드에는 Android SDK/NDK 등이 필요합니다. Windows에서는 WSL 또는 GitHub Actions 빌드를 사용할 수 있습니다.
- 계정과 저장 파일은 각 기기에 저장됩니다. 온라인 계정 공유/클라우드 동기화는 포함되어 있지 않습니다.

APK 빌드: GitHub Actions 방법 (개발 환경 설치를 최소화하는 방법)
1. GitHub에서 새 저장소를 만들고 이 ZIP의 폴더 안에 있는 파일들을 업로드합니다.
2. 저장소의 .github/workflows/android.yml 파일이 업로드됐는지 확인합니다.
3. 저장소의 Actions 탭을 엽니다.
4. "Build Android APK" 워크플로를 선택하고 Run workflow를 누릅니다.
5. 빌드가 성공하면 완료된 작업 화면 아래 Artifacts에서 taehyun-rescue-apk를 다운로드합니다.
6. ZIP을 풀면 taehyunrescue-...-debug.apk 파일이 있습니다. Android 기기에 설치해 테스트할 수 있습니다.

주의: 디버그 APK는 테스트/직접 배포용입니다. Google Play에 게시하려면 별도의 서명 및 스토어 준비가 필요합니다.

Windows에서 PC 버전 실행
- taehyun_rescue.py 파일은 이 폴더 바깥의 PC 버전 파일이며, Python + tkinter로 실행합니다.
- python taehyun_rescue.py
