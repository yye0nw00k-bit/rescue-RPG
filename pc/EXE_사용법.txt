천상 키우기 PC 버전

[실행]
천상 키우기.exe를 더블 클릭하면 됩니다.

[조작]
A / D 또는 방향키 : 이동
Space / W / ↑ : 점프
J : 기본 공격
K : 강타(번개 베기, 재사용 대기시간 있음)
L : 물약 사용
F : 자동 공격 켜기/끄기
U : 성장 메뉴
O : 상점
I : 가방
Q : 임무
M : 지도
R : 스킬 메뉴
T : 이야기
F2 : 관리자 메뉴(관리자 계정만)
ESC : 열린 메뉴 닫기 / 로그아웃

[계정과 저장]
계정 로그인, 공용 진행 데이터, 관리자 기능은 인터넷 연결과 게임 API 서버가 필요합니다.
게임은 기존 천상 키우기 프로젝트의 API 주소를 사용합니다.
일부 로컬 설정 파일은 Windows 사용자 폴더의 .taehyun_growing 디렉터리에 저장될 수 있습니다.

[주의]
이 EXE는 서명되지 않은 개인 프로젝트 빌드이므로 Windows SmartScreen 경고가 표시될 수 있습니다.
공식 프로젝트 저장소에서 받은 빌드인지 확인한 뒤 실행하세요.
