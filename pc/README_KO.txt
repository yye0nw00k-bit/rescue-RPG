태현이 구하기(?) - PC 버전 + Android APK 프로젝트
=====================================================

[PC 버전 실행]
1. Python 3이 설치된 Windows 컴퓨터에 이 폴더를 풉니다.
2. 실행하기.bat을 더블클릭하거나 아래 명령을 입력합니다.
   python taehyun_rescue.py
3. pygame 설치는 필요하지 않습니다. Python에 tkinter가 포함되어 있어야 합니다.

[PC 온라인 계정]
- PC 버전은 온라인 API 서버에 접속해 회원가입/로그인을 합니다.
- 모든 PC에서 같은 아이디로 로그인하면 서버에 저장된 같은 진행 데이터를 불러옵니다.
- 기본 API 주소는 https://taehyun-rescue-api.onrender.com 입니다.
- Render 무료 서버는 잠들 수 있어 첫 접속이 느릴 수 있습니다.
- API 서버가 연결되지 않으면 로그인할 수 없습니다.
- 기존 로컬 계정은 서버 계정으로 자동 복사되지 않습니다.
- 관리자는 서버 환경 변수로만 설정하며, 비밀번호를 코드나 GitHub에 적지 않습니다.

[데이터 저장 주의]
- 장기적으로 계정/진행 상황을 보존하려면 API 서버에 PostgreSQL DATABASE_URL이 연결되어 있어야 합니다.
- DATABASE_URL이 없는 테스트 모드는 임시 SQLite를 사용하므로 서버 재시작/재배포 후 데이터가 사라질 수 있습니다.
- 서버 상태는 https://taehyun-rescue-api.onrender.com/health 에서 확인할 수 있습니다. "database":"postgresql"인지 확인하세요.
- Android 버전은 아직 온라인 API에 연결하지 않았습니다.

[Android APK 제작]
- Android 폴더에는 Kivy 기반 모바일 앱과 APK 빌드 설정이 들어 있습니다.
- 가장 간편한 방법은 GitHub Actions의 "Build Android APK" 워크플로를 실행하는 것입니다.
- 빌드가 성공하면 Actions 실행 결과의 Artifacts에서 taehyun-rescue-apk를 내려받을 수 있습니다.

[게임 스토리]
- 총 13개 지역과 13명의 수호 보스가 있습니다.
- 첫 12명의 보스를 쓰러뜨리면 그 지역마다 서로 다른 인물이 등장해
  "태현이는 여기에 없어요. 일단 이거 받으세요."라고 말하고 보상을 줍니다.
- 13번째 최종 보스를 쓰러뜨린 뒤에만 '태현' 이름표가 있는 인물이 등장하며,
  플레이어 닉네임을 넣어 "고마워요 [닉네임], 환생할 기회를 줄게요."라고 말합니다.
- 환생을 선택하면 캠페인 진행을 초기화하고 영구 능력치 보너스를 받습니다.
