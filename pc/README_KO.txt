태현이 구하기(?) - PC 버전 + Android APK 제작 프로젝트
=====================================================

[PC 버전 실행]
1. Python 3이 설치된 Windows 컴퓨터에 이 폴더를 풉니다.
2. 실행하기.bat을 더블클릭하거나 아래 명령을 입력합니다.
   python taehyun_rescue.py
3. pygame 설치는 필요하지 않습니다. Python에 tkinter가 포함되어 있어야 합니다.

[Android APK 제작]
- Android_APK_Project 폴더에는 Kivy 기반 모바일 앱과 APK 빌드 설정이 들어 있습니다.
- 아직 컴파일된 .apk 파일은 포함되어 있지 않습니다. Android SDK/NDK 빌드 환경이 필요하기 때문입니다.
- 가장 간편한 방법은 Android_APK_Project 폴더 안의 파일들을 새 GitHub 저장소 루트에 올린 뒤 Actions에서 "Build Android APK" 워크플로를 실행하는 것입니다.
- 빌드가 성공하면 Actions 실행 결과의 Artifacts에서 taehyun-rescue-apk를 내려받을 수 있습니다. 상세 절차는 Android_APK_Project/README_KO.txt를 읽어 주세요.

[게임 스토리]
- 총 13개 지역과 13명의 수호 보스가 있습니다.
- 첫 12명의 보스를 쓰러뜨리면 그 지역마다 서로 다른 인물이 등장해
  "태현이는 여기에 없어요. 일단 이거 받으세요."라고 말하고 보상을 줍니다.
- 13번째 최종 보스를 쓰러뜨린 뒤에만 '태현' 이름표가 있는 인물이 등장하며,
  플레이어 닉네임을 넣어 "고마워요 [닉네임], 환생할 기회를 줄게요."라고 말합니다.
- 환생을 선택하면 캠페인 진행을 초기화하고 영구 능력치 보너스를 받습니다.
